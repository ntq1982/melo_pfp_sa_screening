This folder contains the Python scripts used to perform the high-throughput computational screening of multi-component Ni-rich layered oxide (MELO) cathodes described in the associated paper.

The workflow includes:

1. Structure generation — generation of multi-component layered oxide structures based on the NCM parent structure.

2. Configurational sampling — sampling of transition-metal configurations and antisite defects.

3. Delithiation — generation of structures with different Li-extraction levels.

4. PFP-based relaxation — structural optimization using the Matlantis Preferred Potential (PFP).

5. Property evaluation — calculation of structural, thermodynamic, and electrochemical descriptors.

6. Ranking and screening — evaluation of the descriptors and identification of promising MELO compositions.

The scripts in this folder provide the computational tools used to generate and analyze the screening dataset reported in the paper.
